# 🌍 FanTravel — Bespoke Overseas Expeditions & Luxury Travel

> **Live Demo Website:** [https://rajsfanopriariyabarisky.github.io/FanTravel-Bespoke-Overseas-Expeditions-Luxury-Travel-Website/](https://rajsfanopriariyabarisky.github.io/FanTravel-Bespoke-Overseas-Expeditions-Luxury-Travel-Website/)

FanTravel adalah platform website travel mewah fully responsive yang dirancang untuk mengurasi pengalaman perjalanan privat berkelas tinggi lintas benua. Website ini dibangun dengan standar UI/UX modern, dilengkapi fitur-fitur interaktif yang dinamis serta performa tinggi tanpa lag di seluruh perangkat (Desktop, Tablet, dan Mobile).

---

## 🌟 Key Features

- 🌓 **Dynamic Theme Switcher & Image Change:** Pengubahan mode terang/gelap (Light/Dark Mode) yang secara otomatis mengalihkan gambar *Hero Background* secara mulus.
- ⏳ **Automated Evergreen Countdown Timer:** Timer hitung mundur keberangkatan eksklusif yang secara otomatis memperbarui target bulan secara dinamis.
- 💱 **Luxury Currency Converter:** Kalkulator estimasi biaya perjalanan real-time dari IDR ke JPY, CHF, dan EUR.
- 🗺️ **Interactive Destination Modals & Route Maps:** Modal detail destinasi yang dilengkapi carousel gambar dan ilustrasi peta rute.
- 📱 **Fully Responsive & Mobile-Optimized:** Tampilan yang disesuaikan presisi untuk layar HP dengan *hamburger navigation menu* dan *smooth scrolling*.
- 🔊 **Ambient Sound & Floating Quick CTA:** Fitur pemutar suara latar ambient serta tombol WhatsApp Fast-Response Concierge.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Scripting:** Pure JavaScript (Vanilla JS ES6+)
- **Typography:** Google Fonts (Syne & Plus Jakarta Sans)
- **Deployment:** GitHub Pages
